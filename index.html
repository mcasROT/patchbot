Step 1 — Export your settings

Step 2 — Upload to GitHub

In your GitHub repo, upload the patchbot-settings.json file alongside your index.html. Commit the changes.

Step 3 — Enter your GitHub Pages URL

Paste your GitHub Pages URL below so the app knows where to load settings from. Only needs to be set once.

How reps get your settings

When a rep opens the link, the app automatically checks for a patchbot-settings.json file in your GitHub repo. If it finds one, it loads it instantly — no action needed from the rep. If you update and re-upload the file, everyone gets the new settings next time they open the app.
