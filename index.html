Your flow (when you make changes)

  1. Make your changes in Vendors or Patch types
  2. Click Save changes
  3. Click Export settings — downloads a .json file
  4. Send that file to your reps via Slack, email, or Drive

Rep flow (first time or after an update)

  1. Open the PatchBot link
  2. Click Load settings file on the banner
  3. Pick the .json file you sent them
  4. Done — settings saved permanently in their browser
